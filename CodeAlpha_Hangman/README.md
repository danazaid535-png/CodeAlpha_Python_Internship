# CodeAlpha Hangman Game

## Description
This is a simple text-based Hangman Game developed in Python as part of the CodeAlpha Python Programming Internship.

## Features
- Random word selection
- Letter-by-letter guessing
- Maximum of 6 incorrect guesses
- Win/Lose game result
- Console-based interface

## Technologies Used
- Python 3

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python hangman.py
```
